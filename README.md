# НОРМА · разметка вопросов врачами

**Ссылка для врачей:** https://aleksandrermolov87-cloud.github.io/norma-doctor-review/

GitHub Pages перенаправляет на работающий тест с общей базой ответов.

**Отдельный опрос о врачебном мышлении:** https://aleksandrermolov87-cloud.github.io/norma-doctor-review/doctor-thinking/

Он содержит 50 ситуаций с вариантами, специфичными для каждой ситуации. Врачу не нужно вводить текст. Это исследование заявленной последовательности решений, а не проверка знаний или автоматическое обучение модели. Набор хранится в [content/doctor-thinking-50.psv](content/doctor-thinking-50.psv); скомпилированный JSON создаёт `python3 scripts/compile-thinking-questions.py`. Ответы этого опроса пишутся в отдельную таблицу и выгружаются на `/doctor-thinking/results` с тем же ключом организатора. Темы сбора данных, неопределённости, диагностической безопасности и коммуникации ориентированы на [материалы AHRQ](https://www.ahrq.gov/diagnostic-safety/resources/issue-briefs/dxsafety-cognitive-load1.html) и [ВОЗ](https://www.who.int/campaigns/world-patient-safety-day/world-patient-safety-day-2024/practical-advice-for-stakeholders); сами варианты составлены для этого опроса и не прошли клиническую валидацию.

Один публичный адрес для нескольких врачей. Участник выбирает один из четырёх вариантов для каждого вопроса, без имени и свободного текста. Ответы сохраняются в общей базе D1 после нажатия «Отправить ответы». Прогресс до отправки хранится только в браузере.

## Набор вопросов

Текущий набор из 50 синтетических вопросов хранится в [content/questions-50.txt](content/questions-50.txt) и опубликован в тесте. Это редакционные кандидаты для оценки врачами, а не клинически одобренные формулировки. Организатор может открыть `/manage`, вставить утверждённые вопросы по одному на строку (не более 100), ввести ключ и сохранить. Общая ссылка обновится без публикации новой версии. Уникальный ID вычисляется из текста вопроса, поэтому изменение формулировки создаёт новый ID. Снимок текста набора сохраняется вместе с каждой отправкой.

Ответы: `ready` — подходит, `clarify` — нужно уточнить, `reject` — не подходит, `unsure` — не могу оценить.

## Выгрузка

Страница `/results` скачивает CSV после ввода того же ключа организатора. Ключ хранится только в секретной переменной среды `EXPORT_KEY` на хостинге. Не добавляйте его в GitHub. CSV содержит ID ответа, время, вопрос и отметку. Имена врачей не собираются; при анонимном режиме нельзя определить, кому принадлежит конкретный ответ. На одном устройстве можно начать новый проход после отправки.

## Разработка

Стек: Vinext / React / Cloudflare D1. Дизайн основан на `norma-web/DESIGN.md`: бумажный фон, зелёный акцент, Literata и IBM Plex Sans. Сайт отдельный от приложения НОРМА и не меняет его клинические контуры.

```sh
npm ci
npm run db:generate
npm run build
```

В `.openai/hosting.json` указан D1 binding `DB`. Миграция в `drizzle/` применяется при публикации Sites.
