# НОРМА · разметка вопросов врачами

Один публичный адрес для нескольких врачей. Участник выбирает один из четырёх вариантов для каждого вопроса, без имени и свободного текста. Ответы сохраняются в общей базе D1 после нажатия «Отправить ответы». Прогресс до отправки хранится только в браузере.

## Набор вопросов

Сейчас опубликован демонстрационный набор из 8 вопросов. Перед рабочей рассылкой замените массив в `app/questions.ts` утверждёнными вопросами (не более 100). У каждого вопроса должен быть уникальный постоянный `id`, текст `text` и группа `group`. Если ответы уже собирались, не переиспользуйте ID для другого вопроса. Снимок текста набора сохраняется вместе с каждой отправкой.

Ответы: `ready` — подходит, `clarify` — нужно уточнить, `reject` — не подходит, `unsure` — не могу оценить.

## Выгрузка

Страница `/results` скачивает CSV после ввода ключа организатора. Ключ хранится только в секретной переменной среды `EXPORT_KEY` на хостинге. Не добавляйте его в GitHub. CSV содержит ID ответа, время и отметку по каждому вопросу. Имена врачей не собираются; при анонимном режиме нельзя определить, кому принадлежит конкретный ответ. На одном устройстве можно начать новый проход после отправки.

## Разработка

Стек: Vinext / React / Cloudflare D1. Дизайн основан на `norma-web/DESIGN.md`: бумажный фон, зелёный акцент, Literata и IBM Plex Sans. Сайт отдельный от приложения НОРМА и не меняет его клинические контуры.

```sh
npm ci
npm run db:generate
npm run build
```

В `.openai/hosting.json` указан D1 binding `DB`. Миграция в `drizzle/` применяется при публикации Sites.
